# PINN Simulation Projects

Physics Informed Neural Networks (PINN) lab projects.

## Prerequisites

- `uv` (for fast venv management)
- `poetry` (for dependency management)

## Quick Start

1.  **Create environment (with uv)**:

    ```bash
    uv venv .venv --python 3.11
    ```

2.  **Activate environment**:

    ```bash
    source .venv/bin/activate
    ```

3.  **Install dependencies**:

    ```bash
    poetry install
    ```

4.  **Run Jupyter Lab**:
    ```bash
    jupyter lab
    ```

## Dependencies

- `torch`, `numpy`, `matplotlib` (Core)
- `imageio` (GIF creation)
